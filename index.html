The Journey of Red Hat Boy (2D game)

The Journey of Red Hat Boy. A 2D endless-runner game where you jump over obstacles to survive and reach a score of 500 to win. I built it to practise JavaScript and learn how games work. It uses timed loops for sprite animation and a scrolling background, randomly generated obstacles with varied gaps, and collision detection based on the player's height and position. It also has sound effects, a start screen, a game-over screen and a win screen. Built with HTML, CSS and JavaScript.
